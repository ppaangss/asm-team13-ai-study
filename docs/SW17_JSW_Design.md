## 1. 문제 정의 및 프로젝트 개요

### 프로젝트 한 줄 정의
파편화된 메모를 AI가 정리하고, 과거 세션과 자동 연결해 미결 항목을 능동적으로 알려주며, 그래프 뷰로 전체 맥락 흐름을 시각화하는 맥락 기억 에이전트

### 서비스 한 줄 정의 (사용자 관점)
"회의/강의 메모를 그냥 던져주면, AI가 알아서 정리하고 지난번에 못 끝낸 것도 알려줘요"

### 서비스 선정 배경
회의나 강의 중 메모를 하다 보면 완성된 문장이 아닌 단어·구절 위주의 파편적인 형태로 작성된다.  
단순히 GPT에게 정리를 맡기는 수준을 넘어, **여러 세션에 걸친 맥락을 누적·추적하고 능동적으로 액션을 취하는** Agentic Workflow를 구현하고자 한다.

### 해결하려는 문제
1. **파편화 문제**: 회의 중 메모는 비구조적·불완전 → 나중에 보면 맥락 파악 불가
2. **망각 문제**: 여러 세션에 걸친 결정사항·피드백이 어디 있는지 기억 못함
3. **미결 추적 문제**: "지난번에 이거 하기로 했는데..." 미완료 항목이 방치됨

### 대상 사용자
회의, 강의, 코칭 등 토의 상황에서 메모하는 습관을 가진 사람 누구나  
(팀 회의 참석자, 교육 수강생, 코칭·멘토링 참여자 등)

### 핵심 가치
단순 정리가 아닌, **시간을 가로질러 연결하고 알아서 챙겨주는 AI 비서**

## 2. 사용자 및 Agent 설계

### 타깃 사용자 페르소나
- 회의·강의·코칭 중 단어/구절 위주로 빠르게 메모하는 사람
- 세션이 끝난 뒤 정리에 시간을 쓰고 싶지 않은 사람
- 지난 세션의 결정사항이나 피드백을 까먹어서 곤란했던 경험이 있는 사람

### Agent의 역할
1. **정리 에이전트**: 파편화된 텍스트 메모 → 제목/요약/키워드/액션아이템으로 구조화
2. **연결 에이전트**: 새 메모 입력 시 ChromaDB에서 관련 과거 세션을 탐색, 연결점 탐지
3. **미결 감지 에이전트**: 과거에 등록된 미완료 액션아이템이 새 메모에 다시 등장하면 능동 알림

### Agent의 자율성 범위
- **입력 시 자동 실행**: 메모 제출 → 구조화 → 연결 탐색 → 미결 감지까지 자동
- **알림은 UI 표시**: 능동 알림은 앱 내 UI로 표시 (외부 발송은 MVP 제외)
- **실행은 사용자 확인 후**: 캘린더 등록 등 액션은 사용자가 버튼 클릭으로 승인 (MVP는 시뮬레이션)

## 3. 핵심 기능 및 사용자 흐름

### 주요 사용자 시나리오

> 소마 연수생 A씨는 오늘 코치님과 3번째 미팅을 했다.  
> 메모장에 "MVP 범위 다시 줄이기 / 지난번 UI 피드백 아직 못함 / 다음주까지 API 연결" 같은 단어들을 흘려 적었다.  
> 앱에 붙여넣기 하자 AI가 자동으로 구조화하면서,  
> "2주 전 미팅에서 UI 피드백 받은 항목이 아직 미완료 상태예요" 라고 먼저 알려준다.  
> 그래프 뷰에서 'UI 개선' 노드가 오늘 세션과 연결되는 것을 시각적으로 확인할 수 있다.

### 핵심 기능 정의

| 기능 | 설명 | MVP 포함 |
|------|------|---------|
| 📝 메모 구조화 | 파편 텍스트 → 제목/요약/키워드/액션아이템 자동 추출 | ✅ |
| 💾 세션 저장 | 세션별 임베딩 생성 후 ChromaDB에 저장 | ✅ |
| 🔗 맥락 연결 | 새 메모 입력 시 유사 과거 세션 자동 탐색·표시 | ✅ |
| ⚠️ 미결 감지 | 과거 미완료 액션아이템이 다시 등장하면 능동 알림 | ✅ |
| 🕸️ 그래프 뷰 | 주제·세션 간 관계를 노드-엣지로 시각화 | ✅ (간소화) |
| 🔍 자연어 검색 | "저번에 ~했던 거 뭐였지?" 자연어 검색 | ❌ (향후 확장) |
| 📅 액션 실행 | 미결 항목 → 캘린더/알림 자동 생성 | ❌ (향후 확장) |

### 사용자 관점 워크플로우

```
1. 메모 입력       → Streamlit 텍스트 영역에 파편 메모 붙여넣기
2. 자동 구조화     → AI가 제목/요약/키워드/액션아이템으로 변환
3. 맥락 연결 표시  → "이전 세션 N개와 연결됐어요" + 연결 내용 표시
4. 미결 항목 알림  → "지난번에 이 항목이 미완료였는데 오늘도 언급됐어요" 배너
5. 그래프 뷰 확인  → 주제별 노드-엣지 시각화로 전체 흐름 한눈에 파악
6. 세션 저장       → ChromaDB에 임베딩 저장, 다음 세션의 맥락으로 활용
```

## 4. 기술 구현 설계

### 기술 스택

| 영역 | 기술 |
|------|------|
| UI | Streamlit |
| LLM | Claude API (claude-sonnet-4-6) |
| Vector DB | ChromaDB (로컬 실행) |
| 시각화 | Plotly 또는 Pyvis |
| 언어 | Python 3.13 |
| 배포 | 로컬 실행 / GitHub |

### 시스템 아키텍처

```
[입력]                [처리]                     [저장]
텍스트 메모  →  정리 에이전트 (Claude)  →  ChromaDB (임베딩)
                       ↓                        ↑
                  연결 에이전트  ←── 유사도 검색 ─┘
                  미결 감지 에이전트
                       ↓
[출력]
구조화된 노트 / 연결된 과거 세션 / 미결 알림 / 그래프 뷰
```

### 핵심 컴포넌트

```
project/
├── app.py                  # Streamlit 메인 앱
├── agents/
│   ├── organizer.py        # 정리 에이전트 (Claude API)
│   ├── connector.py        # 연결 에이전트 (ChromaDB + Claude)
│   └── tracker.py          # 미결 감지 에이전트
├── memory/
│   └── vector_store.py     # ChromaDB 인터페이스
├── ui/
│   └── graph_view.py       # 그래프 시각화 (Plotly)
└── models/
    └── session.py          # 세션 데이터 모델
```

### 프롬프트 설계 원칙
- **정리 에이전트**: 입력(파편 메모) → 출력(JSON: 제목, 요약, 키워드 리스트, 액션아이템 리스트)
- **연결 에이전트**: 현재 세션 + 유사 세션 목록 → 연결점 설명 생성
- **미결 에이전트**: 과거 액션아이템 리스트 + 현재 세션 → 미결 여부 판단

### 제약사항 및 예외 처리

| 항목 | 내용 |
|------|------|
| ❌ 음성 입력 | MVP 제외, 텍스트만 지원 |
| ❌ 멀티유저 | 단일 사용자 로컬 환경만 지원 |
| ❌ 자연어 검색 | 향후 확장 |
| ❌ 실제 캘린더/알림 | MVP는 UI 내 시뮬레이션 |
| ⚠️ LLM 비용 | Claude API 호출 횟수에 따라 비용 발생 |
| ⚠️ 인터넷 필요 | Claude API 호출을 위한 네트워크 필요 |
| ⚠️ 빈 메모 입력 | 최소 50자 이상 입력 유도, 미만 시 안내 메시지 |
| ⚠️ 첫 세션 | 과거 세션 없을 때 "아직 연결할 이전 기록이 없어요" 안내 |

## 5. 성과 평가 및 실행 계획

### MVP 범위
**이번에 반드시 만드는 것**
- 텍스트 메모 입력 → 자동 구조화
- ChromaDB 세션 저장 & 임베딩
- 과거 세션 맥락 연결 & 미결 감지 알림
- 기본 그래프 뷰 (노드-엣지)

**이번에 하지 않는 것**
- 음성 입력 (STT)
- 자연어 검색
- 실제 캘린더/알림 API 연동
- 멀티유저 지원

> 목표: 로컬 환경에서 실행 가능한 Agentic Workflow 데모 프로젝트

### 2주 개발 로드맵

```
Week 1 — 정리 파이프라인 완성
  Day 1-2  │ 프로젝트 셋업 + Streamlit UI 기본 구조
  Day 3-4  │ Claude API 연동 → 파편 메모 구조화 구현
  Day 5-6  │ ChromaDB 연동 → 세션 저장 & 임베딩
  Day 7    │ Week 1 통합 테스트 & 버그 수정

Week 2 — 에이전트 + 데모 완성
  Day 8-9  │ 맥락 연결 에이전트 (유사 세션 탐색·표시)
  Day 10-11│ 미결 항목 감지 + 능동 알림 UI
  Day 12-13│ 그래프 뷰 구현 (Plotly 간소화)
  Day 14   │ 전체 데모 시나리오 완성 & 리허설
```

### 성공 지표
- 파편 메모 → 구조화 변환이 자연스럽게 동작하는가
- 관련 과거 세션을 정확하게 연결하는가
- 미결 항목을 놓치지 않고 능동적으로 알려주는가
- 그래프 뷰에서 맥락 흐름이 직관적으로 보이는가

### 향후 확장 계획
- 음성 입력 (Whisper STT)
- 자연어 기반 맥락 검색
- 실제 캘린더(Google Calendar) / 알림 연동
- 멀티유저 & 팀 공유 기능
